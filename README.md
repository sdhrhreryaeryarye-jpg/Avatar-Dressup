# Примерочная аватаров

Страница, где зритель собирает персонажа из слоёв, смотрит анимированное превью, копирует JSON для награды за баллы и хранит любимых персонажей в избранном.
Программа (`index.html`, `avatar.js`, `emotions.js`) и ассеты (`assets/`) разделены: чтобы добавить костюм, достаточно положить PNG в папку и пересобрать каталог.

## Что где лежит

```
index.html            страница-примерочная
avatar.js             сам аватар: слои, моргание, речь, тряска, прыжок, эмоции (его же возьмёт страница чата)
emotions.js           слова-триггеры, тайминги, настройка эмоций (правится руками)
catalog.js/.json      каталог (создаёт скрипт; руками правятся только dx/dy/scale/label/hides/order/face.params)
update_catalog.py     пересобирает каталог по папке assets/
split_grid.py         режет картинки-сетки 2x2 на отдельные ассеты
streamerbot_items.txt список id для Streamer.bot (создаётся скриптом)
assets/
  base/ eyes/ hair/ outfit/ hat/ acc/    предметы, которые выбирает зритель
  face/                                  слои лица для анимации (зритель их не выбирает)
```

Сейчас в `assets/` лежат **цветные заглушки**, чтобы проверить интерфейс и анимацию. Перед публикацией удали их и положи свои файлы.

## Правила имён

**Предметы:** `assets/<слот>/<слот>_<название>.png`, например `assets/hat/hat_witch.png`. Слоты: `base` (тело), `eyes` (глаза с цветом), `hair`, `outfit`, `hat`, `acc`. Только строчные латинские буквы, цифры и `_`. Это же id предмета в JSON и в Streamer.bot.

**Слои лица:** `assets/face/<вид>_<название>.png`. Анимация знает такие:

| Вид | Названия |
|---|---|
| `mouth` | closed, open, smile, frown, wavy, o, shout, laugh |
| `brow` | neutral, angry, sad, surprised |
| `eyex` (особые глаза вместо обычных) | happy, relaxed, squeeze, dot |
| `fx` (эффекты) | blush, sweat, vein, sparkle, tears, gloom, heart, excl |

Если какого-то слоя нет, он просто не показывается, а анимация использует запасной (например, нет `mouth_laugh`, тогда будет `mouth_open`). `update_catalog.py` пишет, чего не хватает.
Рот и брови могут отличаться у баз: положи свой вариант в `assets/face/male/` или `assets/face/female/` (имя папки = id базы без `base_`), он заменит общий для этой базы.

Порядок слоёв: тело, глаза, особые глаза, брови, рот, одежда, причёска, головной убор, аксессуар, эффекты. Меняется в `order` в `catalog.json`. Если причёска закрывает брови, а ты хочешь наоборот, переставь `brow` после `hair`.

## Как добавить новые ассеты

1. Убери пурпурный фон (`#FF00FF`) с картинки-сетки вручную. Или добавь флаг `--remove-magenta`, но он вырезает чисто только ровный фон.
2. Нарежь сетку 2×2 (нужен Pillow, `pip install pillow`):
   ```
   python split_grid.py dresses.png outfit maid evening sailor sundress --size 256
   python split_grid.py mouths1.png mouth closed open smile frown --base male
   python split_grid.py brows.png brow neutral angry sad surprised
   python split_grid.py fx1.png fx blush sweat vein sparkle
   ```
   Порядок названий: верхняя левая, верхняя правая, нижняя левая, нижняя правая. Прочерк `-` пропускает ячейку. `--size 256` уменьшает без сглаживания, чтобы пиксели остались чёткими.
3. Пересобери каталог (ничего ставить не нужно): `python update_catalog.py`
4. Открой страницу и проверь. Если слой съехал, поправь у предмета в `catalog.json` поля `dx`, `dy` (доли от ширины, например `0.02`) и `scale`, затем снова запусти `update_catalog.py` (значения сохранятся). Высота линии глаз для моргания: `face.params.eyeY` (по умолчанию `0.42`).

### Шлем прячет причёску

В `catalog.json` в блоке `hides` перечисли, какие слоты скрывает предмет:
```json
"hides": { "hat_witch": ["hair"], "hat_knight_helmet": ["hair"] }
```
Эти значения скрипт не затирает.

## Анимация

Поле «Сказать» в примерочной показывает, как аватар отреагирует на сообщение. Под полем виден разбор: эмоция, капс, прыжок, длина реакции.

- Рот двигается только первые секунды: `0,8 с + 0,06 с на символ`, не меньше 1 и не больше 6 секунд. Ссылки, `@упоминания` и эмоуты в длину не считаются, сообщение из одних эмоутов реакцию не запускает.
- Капс: заглавных не меньше 70% букв и букв не меньше 5. Аватар трясётся, рот кричит, глаза «> <».
- Прыжок в начале реакции, только если в сообщении есть `!`.
- Эмоция выбирается по словам из `emotions.js` (покерфейс, радость, злость, грусть, смущение, удивление). Побеждает та, у которой больше совпадений, при ничьей приоритет такой: злость, грусть, смущение, удивление, радость, покерфейс. Свои слова и эмоуты добавляй в списки в `emotions.js`: `круто` ищет слово целиком, `круто*` любое, что начинается так, `ну ок` ищет фразу, `))` ищет символы.
- Идл: моргание раз в 2-6 секунд, взгляд в сторону, дыхание. Эмоция держится ещё 1,4 с после речи и возвращается в спокойное состояние.
- Свечение вокруг персонажа (красное у злости, синее у грусти и так далее) задаётся в `emotions.js` в поле `aura`.

Ограничение: разбор по словам не понимает отрицание и иронию.

## Избранное

Внизу страницы окно «Избранные персонажи»: сохранить текущего (с названием или без), надеть кликом по миниатюре, кнопки ‹ › листают избранных по кругу, а на карточке есть ↻ (заменить текущим образом), ✎ (переименовать) и ✕ (удалить). Избранное хранится в браузере зрителя (на каждом устройстве своё), поэтому для переноса есть блок «Перенос между устройствами»: копируешь список на одном и добавляешь на другом. Если предмет потом удалили из каталога, при надевании он молча пропускается.

## Локальная проверка

Двойным кликом по `index.html` картинки могут не загрузиться (зависит от браузера), а избранное в некоторых браузерах не сохранится. Надёжнее запустить в папке:
```
python -m http.server 8000
```
и открыть `http://localhost:8000`.

## Публикация на GitHub Pages (бесплатно для публичного репозитория)

1. Заведи аккаунт на github.com и создай **публичный** репозиторий, например `avatar-dressup`.
2. Загрузи в него все файлы из этой папки (Add file → Upload files; папку `.github` перетащи тоже).
3. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)` → Save.
4. Через минуту-две страница будет по адресу `https://<твой-ник>.github.io/avatar-dressup/`. Эту ссылку клади в описание канала и в Telegram.

Обновление костюмов: положи новые PNG в `assets/...` и залей на GitHub. Файл `.github/workflows/update-catalog.yml` сам пересоберёт каталог при заливке. Без него запусти `update_catalog.py` у себя и залей `catalog.js` и `catalog.json`. Версия каталога растёт сама и сбрасывает кэш картинок у зрителей.

## Streamer.bot

1. После каждого обновления каталога вставь содержимое `streamerbot_items.txt` в `HashSet<string> Items` в действии на награду (список хранится у тебя, а не в присланном JSON). Слои лица в список не попадают: зритель их не выбирает.
2. JSON, который копирует кнопка:
   ```
   {"base":"base_female","eyes":"eyes_blue","hair":"hair_red","outfit":"outfit_maid","hat":"hat_witch","acc":""}
   ```
   Бот должен: разобрать JSON, проверить каждый слот (id есть в списке и префикс совпадает со слотом), всё лишнее выбросить, при ошибке отменить награду и вернуть баллы, а проверенный результат записать в профиль зрителя целиком.
3. Цвет ника в JSON не входит: он приходит из Твича или выбирается случайно из стандартной палитры.
4. Страница чата будет подключать `catalog.js`, `emotions.js` и `avatar.js` и вызывать `av.setProfile(профиль)` и `av.react(текст, {emotes: [...]})`. Это следующий шаг.
